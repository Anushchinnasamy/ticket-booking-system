Phase F4 — Idempotency-safe Pay button
What happens on click
A UUID idempotency key is generated the moment this screen loads and sent with the charge request. The button disables the instant it's clicked — not just visually — so a second click (or a slow network causing a double-tap) can never fire a second charge. The same key is reused if the request is retried.
